
## Configuration de la base de données

Chaque développeur doit créer son propre `App.config` :

- **Windows / MySQL** : copie `App.config.mysql.example` → `App.config`
- **Debian / PostgreSQL** : copie `App.config.postgres.example` → `App.config`

Le fichier `App.config` n'est pas versionné dans Git.
